# v1.0.0 — research publication package

Initial consolidation of Saksham Chopra's completed WinGo 30S research.

- Canonical 88,916-round archive and 88,911-example ML export, with master workbook and checksums.
- Snapshot reconciliation: 51 additional rounds and 49 completed premiums, with no changed overlapping winning digits.
- Master README, detailed whitepaper, methods, limitations, infrastructure notes and claim ledger.
- Preserved saved-model evaluation evidence, the 5,000 prediction rows and historical protocol/catalogue.
- Inventory of 12 locally preserved saved models, broader file inventory and duplicate decisions.
- Explicitly guarded legacy scripts and an offline integrity-check wrapper.
- Medium/Substack and LinkedIn article drafts, MIT license, attribution notes and citation metadata.

No new model training or game-server investigations were performed. This release does not recover a seed, certify a deployed RNG, or guarantee predictive accuracy. Some original audit verdicts are unsupported; their corrections are documented.

## Release process

- Validate the sample and full raw/ML files; run the publication checks.
- Check every staged file and release asset for credentials/private metadata.
- Check local Markdown links, Python syntax and source/evidence hashes.
- Verify the authenticated GitHub account before creating the public repository.
- Push the reviewed publication commit and prepare a `v1.0.0` draft release with the assets above.
- Confirm repository visibility, remote commit and uploaded asset sizes.

Article files are drafts only; creating this repository does not publish them to other platforms. The release is prepared as a draft so its accompanying announcement and publication time can be chosen separately.
